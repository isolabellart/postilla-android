# Postilla 1.0.80

## Concord Groups
- Improved channel read readiness using a verified relay EOSE quorum, while keeping full Control Plane reads mandatory for administrative changes.
- Restored the community owner's ordinary channel capabilities without bypassing private-channel keys or restricted writer credentials.
- Refreshes the displayed group name and description from current Concord Control Plane metadata.
- Adds an authorized group-details editor for name, description and bootstrap relays; relay URLs are normalized and invalid or insecure entries are rejected.
- Preserves encrypted icon/banner pointers, message-expiration timers and unknown metadata fields when publishing a metadata edit.
- Uses current folded group metadata for new invite previews and relay delivery, avoiding stale names and relay hints.
- Prepares writer access for restricted channels where @everyone cannot send, including first-time writer-plane setup.
- Uses a strict greater-than-two-thirds relay quorum for writer-duty readiness and keeps full Control Plane reads mandatory for administrative changes.
- Expands the member roster with the proven owner and live role-holders, and adds a bounded, resumable history harvest for observed members.
- Improves the feedback shown when channel or writer-access synchronization has not reached its required quorum.

## App updates
- The official app checks GitHub Releases when the app is opened and continues periodic checks while running.
- The update panel displays the release-specific notes published with each version.
- Preview builds no longer show a fabricated update offer or attempt to install a production APK.

## Reliability
- Adds regression tests for relay quorum, owner channel permissions and privileged member-roster entries.

# Postilla 1.0.80 (Italiano)

## Gruppi Concord
- Migliorata la disponibilità dei canali tramite quorum EOSE verificato dei relay; le modifiche amministrative continuano invece a richiedere la lettura completa del Control Plane.
- Ripristinati i normali permessi di canale del proprietario, senza aggirare le chiavi dei canali privati o le credenziali degli stream di scrittura riservati.
- Aggiorna il nome e la descrizione del gruppo leggendo i metadati correnti del Control Plane Concord.
- Aggiunta la modifica autorizzata di nome, descrizione e relay di bootstrap; gli indirizzi vengono normalizzati e quelli non validi o non sicuri rifiutati.
- Le modifiche ai metadati conservano i puntatori cifrati di icona/banner, il timer di scadenza dei messaggi e i campi sconosciuti.
- I nuovi inviti utilizzano nome e relay correnti del gruppo, evitando anteprime obsolete.
- Preparazione degli stream di scrittura anche per i canali restricted in cui @everyone non può inviare messaggi, inclusa la prima inizializzazione del writer plane.
- Quorum writer-duty strettamente superiore ai due terzi dei relay; le modifiche amministrative continuano a richiedere la lettura completa del Control Plane.
- Esteso il roster dei membri includendo il proprietario verificato e i titolari di ruoli attivi, con recupero storico progressivo e limitato degli autori osservati.
- Migliorati i messaggi che spiegano quando la sincronizzazione dei canali o degli accessi di scrittura non ha ancora raggiunto il quorum necessario.

## Aggiornamenti dell'app
- L'app ufficiale controlla le release GitHub all'apertura e continua a effettuare verifiche periodiche durante l'utilizzo.
- Il riquadro di aggiornamento mostra le note specifiche della versione pubblicata.
- Le build Preview non mostrano più offerte di aggiornamento fittizie e non propongono l'installazione di APK di produzione.

## Affidabilità
- Aggiunti test di regressione per quorum dei relay, permessi di canale del proprietario e inclusione dei membri privilegiati.
