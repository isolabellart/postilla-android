# Archived GitHub Actions workflow snapshots

These YAML files are historical, version-specific workflow snapshots moved out of `.github/workflows/` during the Postilla mainline cleanup.

They are retained for inspection and provenance. GitHub Actions does not discover or execute workflows from this directory. The corresponding tags, release branches and original Git history remain preserved.

Do not copy an archived workflow back into `.github/workflows/` or dispatch it without checking its pinned source SHA, branch filters, version, secrets, artifact names and publication side effects.

Current workflow entry points are documented in [docs/CI_CD.md](../../CI_CD.md).
